# Personal Project Showcase App

A React-based web application for showcasing and managing personal projects.

## Features
- Add new projects
- Search through projects
- Display project cards with descriptions
- Responsive and clean UI design

## Technologies Used
- React
- Vite
- JavaScript
- CSS

## Project Structure
src/
├── components/
├── pages/
├── data/
├── styles/

## Installation & Setup

1. Clone the repository

git clone https://github.com/dgm688/pixelforge-portfolio.git

2. Navigate into the project folder

cd pixelforge-portfolio

3. Install dependencies

npm install

4. Start the development server

npm run dev
